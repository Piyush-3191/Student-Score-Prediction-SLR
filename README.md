# Student Exam Score Prediction

## 📌 Project Description

This project predicts a student's **exam score based on study hours** using **Simple Linear Regression**.

## 🎯 Objective

To find the relationship between **study hours** and **exam scores** and predict the expected score for a given number of study hours.

## 🧠 Algorithm

**Simple Linear Regression**

* **Independent Variable (X):** Study Hours
* **Dependent Variable (Y):** Exam Score

## 🛠️ Technologies Used

* Python
* Pandas
* Matplotlib
* Scikit-learn
* Google Colab

## 📊 Dataset

The dataset contains two columns:

* `Study Hours`
* `Exam Score`

## ⚙️ Steps

1. Load the dataset.
2. Split data into training and testing sets.
3. Train the Linear Regression model.
4. Predict exam scores.
5. Evaluate the model.
6. Visualize the regression line.

## 📈 Result

The model predicts exam scores based on the number of hours studied and shows the relationship using a regression line.

## 🔮 Future Scope

More features such as **attendance, previous marks, sleep hours, and practice test scores** can be added to improve prediction accuracy.
